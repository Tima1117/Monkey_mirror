# Monke Mirror 🐒

Веб-приложение, которое смотрит на тебя через камеру и переключает картинки обезьяны в зависимости от мимики и жестов.

## Реакции

- Обычный — состояние по умолчанию.
- Со стаканом — стакан в руке.
- Грустный — грустная мимика или наклон головы.
- Улыбается — улыбка.
- Задумался — палец у рта и взгляд вверх.
- В солнечных очках — тёмные очки.

## Запуск

Открой `Monke-Mirror.html` в Chrome на компьютере и разреши доступ к камере. Для загрузки моделей нужен интернет.

Для публикации на статическом хостинге используй папку `dist` и HTTPS. Сборка, сервер и API-ключи не нужны.

## Возможности

Автоматическое и ручное переключение, деморежим, калибровка под лицо, отображение точек лица и рук, полноэкранный вывод картинки.

## Как работает

JavaScript + MediaPipe: анализ лица, рук и объектов выполняется в браузере через Web Worker. Видео не отправляется на сервер, микрофон не используется.

Грусть и солнечные очки определяются приблизительно. Хорошее освещение и калибровка улучшают результат; если реакция не распознана, показывается обычная картинка.

## Zoom и Телемост через OBS

1. Установи OBS Studio с https://obsproject.com/. Открой HTML в Chrome на компьютере.
2. Включи камеру в Monkey Mirror, затем нажми **Окно для OBS**.
3. В OBS создай отдельную сцену и добавь захват окна **Monke Mirror — OBS**. На macOS используй источник захвата macOS в режиме окна; системе потребуется разрешение записи экрана.
4. Обрежь рамку браузера, если она попала в захват (Alt/Option + край источника), и подгони изображение под холст. В сцене должна остаться только обезьяна.
5. Запусти виртуальную камеру OBS; выбери **OBS Virtual Camera** в настройках видео звонка. Микрофон остаётся обычным.

Оставь основную вкладку открытой и окно вывода не свёрнутым. Если браузер замедляет распознавание в фоне, держи основную вкладку видимой. Для проверки без камеры нажми «Демо без камеры» или переключай карточки вручную. Вывод синхронизируется во всех режимах; камера и интерфейс в него не копируются. При закрытии основной страницы окно вывода закрывается.

Это режим вывода для OBS, а не самостоятельный драйвер камеры. Совместимость с конкретной ОС и приложением звонков проверяется на компьютере пользователя. Инструкция OBS: https://obsproject.com/kb/virtual-camera-guide

## Без браузера: консольная версия для Windows и Linux

В папке `monkey-cam` лежит программа, которая сама создаёт виртуальную камеру с обезьяной для Zoom и Телемоста, без захвата окна в OBS. Запуск: `run.bat` на Windows или `./run.sh` на Linux. Подробности в `monkey-cam/README.md`.
