# Monkey Cam 🐒: обезьяна вместо камеры в Zoom и Телемосте

Консольная версия Monke Mirror для Windows и Linux. Программа смотрит в твою настоящую камеру, распознаёт мимику и жесты и отдаёт в звонок виртуальную камеру, где вместо тебя обезьяна. Реакции и алгоритм те же, что в веб-версии: обычная, со стаканом, грустная, улыбка, задумался, в очках.

Распознавание работает локально на компьютере, видео никуда не отправляется. Микрофон остаётся обычным.

## Windows

1. Один раз установи:
   - Python 3 с https://www.python.org/downloads/ (при установке отметь **Add python.exe to PATH**);
   - OBS Studio с https://obsproject.com/. Из него нужен только драйвер виртуальной камеры, сам OBS запускать не надо.
2. Открой папку `monkey-cam` и запусти `run.bat`: двойным кликом или из терминала. Первый запуск несколько минут ставит зависимости.
3. В Zoom/Телемосте выбери камеру **OBS Virtual Camera**.

Если у тебя открыт OBS с включённой виртуальной камерой, выключи её: камера может работать только с одной программой.

Без OBS можно взять драйвер Unity Capture (https://github.com/schellingb/UnityCapture, установка через `Install.bat` от администратора) и запускать так: `run.bat --backend unitycapture`.

## Linux

```bash
sudo ./setup-linux.sh   # один раз: создаёт виртуальную камеру «Monkey Cam»
./run.sh
```

В звонке выбери камеру **Monkey Cam**. Сначала запусти программу, потом выбирай камеру: Chrome показывает её только пока в неё идёт картинка.

Если загрузка модуля не удалась из-за Secure Boot, подпиши модуль (DKMS предлагает это при установке) или отключи Secure Boot.

## Управление

В терминале (или в окне проверки):

| Клавиша | Что делает |
|---|---|
| 1–6 | показать картинку вручную: 1 обычная, 2 стакан, 3 грустная, 4 улыбка, 5 задумался, 6 очки |
| A | вернуться к авто-распознаванию |
| C | калибровка: смотри в камеру с обычным лицом и нажми, распознавание станет точнее |
| P | показать или скрыть окно проверки с точками лица |
| Q / Esc / Ctrl+C | выход |

Клавиши работают и в русской раскладке.

## Параметры запуска

```
run.bat --camera 1               другая камера, если открылась не та
run.bat --size 1920x1080         размер картинки в звонке (по умолчанию 1280x720)
run.bat --images D:\my-monkeys   свои картинки: default/cup/sad/smile/think/glasses .jpg/.png
run.bat --no-preview             без окна проверки
run.bat --no-virtual             без виртуальной камеры, только проверить распознавание
```

На Linux то же самое через `./run.sh`. Дополнительно есть `--device /dev/video10`, если виртуальных камер несколько.

## Если что-то не так

- **Телемост пишет «Включить видео не удалось»**: он пытается открыть настоящую камеру, а её держит Monkey Cam. В настройках звонка выбери **OBS Virtual Camera**.
- **OBS Virtual Camera нет в списке камер**: браузер или Zoom были открыты до установки OBS. Полностью закрой их (у Яндекс Браузера и в трее) или перезагрузи компьютер. Не помогло — найди в папке OBS файл `virtualcam-install.bat` (обычно `C:\Program Files\obs-studio\data\obs-plugins\win-dshow`) и запусти его от имени администратора.
- **«Не получилось открыть камеру»**: камеру держит другая программа. В Zoom должна быть выбрана виртуальная камера, а не настоящая. Или попробуй `--camera 1`.
- **В окне проверки не ты, а обезьяна**: программа открыла виртуальную камеру вместо настоящей. Запусти с `--camera 1` (или 2).
- **У себя в Zoom обезьяна отзеркалена**: так Zoom показывает твоё видео только тебе, собеседники видят нормально. Отключается в настройках видео Zoom: «Зеркальное отображение».
- **Ошибка «DLL load failed» на Windows**: поставь Microsoft Visual C++ Redistributable (https://aka.ms/vs/17/release/vc_redist.x64.exe) и запусти снова.
- **Реакция не срабатывает**: нажми C с обычным лицом и проверь освещение. Грусть и очки распознаются приблизительно.
